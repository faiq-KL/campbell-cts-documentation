# campbell-cts-documentation

Documentation for moving Campbell CTS production off the VM and into the webapp. We are in the discovery phase.

## Pages

- [VM to Webapp Plan](vm-to-webapp-plan.html): how production works today, in seven flows. Click any card to see what happens now, what could be optimized, and a priority for each point.

## Docs

Detailed notes for the team. They live in this repo only and are not published on the site.

- [How it works today](https://github.com/faiq-KL/campbell-cts-documentation/blob/main/docs/how-it-works-today.md): each flow step by step, as production runs now.
- [Suggestions and needs](https://github.com/faiq-KL/campbell-cts-documentation/blob/main/docs/suggestions-and-needs.md): what we suggest for each flow, and what we need to get there.
- [Card details](https://github.com/faiq-KL/campbell-cts-documentation/tree/main/docs/cards): every card in full, one file per flow. Each card on the page links to its section here.
- [Words used](https://github.com/faiq-KL/campbell-cts-documentation/blob/main/docs/words-used.md): plain meanings of the terms on the page and in these docs.
