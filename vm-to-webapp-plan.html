Flow 1

Track model changes and update schedules

Twice each weekday the bot reads each 3D model, finds what changed since the last run, and updates the schedule spreadsheets and web pages. Each morning it also checks the trades' combined models for clashes, and holds anything risky for the client.

100%
Flow 2

Automate RFIs, notes and meeting prep

AI jobs run on timers all day. They file RFIs and submittals, keep the project notes, prepare meetings and email summaries, while three watchers check that everything ran.

100%
Flow 3

Review, approve and carry out

Anything unusual waits for a person. The client decides in chat, Triad signs off schedule cards, and the AI then carries out exactly what was approved.

100%
Flow 4

Catch and fix failed runs

When a run or a job fails, a watcher alerts the client. The client finds the cause on the VM, then restarts or re-runs what failed, with a backup PC as the last resort.

100%
Flow 5

Sell and support Conduit

The company also sells conduit, its Revit and Navisworks software. Releases are built and uploaded for licensed download, and an AI chat on the website answers customers.

100%
Flow A

Release code changes

Code changes come from coding sessions and land on GitHub. Saving to a repo's main branch puts the pages and the website live, while the VM runs its own copy of the code.

100%
Flow B

Onboard a new project

A new project starts with an AI interview of the client. The answers become two settings files, then the bot adds the project and its pages are copied from an existing project.

100%
